## MVP-6 · Cómo arrancar y usar la herramienta

### Arrancar el servidor API

```bash
uv run uvicorn src.rosetta.api.main:app --reload
```

El servidor arranca en `http://localhost:8000`.

### Variables de entorno relevantes

| Variable | Descripción | Valor por defecto |
|----------|-------------|-------------------|
| `LLM_PROVIDER` | Proveedor LLM (`claude`, `ollama`, `openai`) | `claude` |
| `ANTHROPIC_API_KEY` | Clave de API de Anthropic (obligatoria si `claude`) | — |
| `CHROMADB_PATH` | Ruta a la base vectorial ChromaDB | `.chroma` |
| `ROSETTA_MARCOS` | Marcos activos separados por coma | `iso_27001_2022` |
| `NEO4J_URI` | URI de Neo4j (opcional — sin él la API sigue funcionando) | — |

Para desarrollo con Ollama:
```bash
LLM_PROVIDER=ollama uv run uvicorn src.rosetta.api.main:app --reload
```

### Interfaces web disponibles

| URL | Para quién | Qué hace |
|-----|-----------|----------|
| `http://localhost:8000/dashboard` | Auditor / usuario final | Panel visual (ver abajo) |
| `http://localhost:8000/docs` | Desarrollador | Swagger UI con todos los endpoints |
| `http://localhost:8000/redoc` | Documentación | ReDoc con esquemas completos |

### Panel `/dashboard` — tres secciones

**1. Traducir hallazgo**
- Textarea con JSON de ejemplo pre-cargado (fuga de clave AWS)
- Selector de marco normativo (ISO 27001, ENS, NIS2, DORA, NIST CSF)
- Botón "Traducir" → llama a `POST /translate` → muestra controles incumplidos, impacto legal, acción de mitigación, cita normativa

**2. Estado de cumplimiento**
- Selector de marco → botón "Consultar estado"
- Muestra: total hallazgos, barras de controles más incumplidos, distribución por severidad

**3. Hallazgos de sesión**
- Tabla con todos los hallazgos traducidos en la sesión actual
- Se actualiza automáticamente tras cada traducción

### Endpoints API

| Método | Ruta | Descripción |
|--------|------|-------------|
| `GET` | `/health` | Smoke test |
| `POST` | `/translate` | Traduce hallazgo → evidencia normativa |
| `GET` | `/findings` | Lista hallazgos con paginación (`?offset=0&limit=20`) |
| `GET` | `/compliance/state/{marco}` | Estado de cumplimiento por marco |
| `GET` | `/dashboard` | Panel visual HTML |

### Ejemplo rápido con curl

```bash
curl -s -X POST http://localhost:8000/translate \
  -H "Content-Type: application/json" \
  -d '{
    "hallazgo": {
      "origen": "github_secrets",
      "activo_detectado": "AWS_ACCESS_KEY_ID en repo público",
      "evidencia": "https://github.com/org/repo/commit/abc123",
      "vector_ataque": "Exposición de credencial cloud en código fuente",
      "dificultad_explotacion": "baja"
    },
    "marcos": ["iso_27001_2022"]
  }' | python -m json.tool
```

### Neo4j es opcional

Sin `NEO4J_URI`, los hallazgos se guardan en memoria durante la sesión (se pierden al reiniciar el servidor). Para activarlo con Docker:

```bash
docker compose up -d neo4j
NEO4J_URI=bolt://localhost:7687 uv run uvicorn src.rosetta.api.main:app --reload
```
