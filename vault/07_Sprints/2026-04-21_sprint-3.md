# Sprint 3 · MVP-7 Gate CI/CD

## Objetivo

Implementar el Gate de CI/CD: una GitHub Action reutilizable que llame a la API de ROSETTA sobre el diff de un PR, y bloquee el merge si el cambio introduce incumplimientos normativos. Criterio de aceptación del ROADMAP: un PR con un secret hardcodeado queda bloqueado con motivo ISO 27001 A.8.24.

## Contexto de inicio

- **Último commit**: `af89a59 feat(mvp-6): API REST funcional + dashboard visual en /dashboard`
- **Tests**: 102 passing · ruff ✅ · mypy strict ✅
- **MVP-6**: ✅ completado — API REST operativa con `/translate`, `/findings`, `/compliance/state/{marco}`, `/dashboard`
- **Diseño MVP-7**: aprobado en sesión 2026-04-19. Decisiones clave:
  - La GitHub Action llama a la API externa de ROSETTA (no embebe lógica)
  - El diff se divide en hunks para granularidad de línea
  - Config en `.rosetta.yml` del repo cliente; `api_key` como GitHub Secret
- **ADR-004**: propuesto (arquitectura multi-agente) — pendiente de aprobación del usuario

## Tareas planificadas

- [ ] Diseñar endpoint `POST /analyze-diff` en la API de ROSETTA (recibe hunks, devuelve incumplimientos)
- [ ] Implementar parser de diff (divide diff de PR en hunks clasificados por archivo+línea)
- [ ] Crear esquema `.rosetta.yml` para configuración por repo (marco activo, umbrales, etc.)
- [ ] Escribir la GitHub Action reutilizable (`action.yml` + shell/composite)
- [ ] Implementar formato de comentario en PR (control incumplido + línea + sugerencia + marco)
- [ ] Tests E2E: PR con secret hardcodeado → bloqueado con A.8.24 ISO 27001
- [ ] Documentar integración en `vault/05_Hallazgos/` y actualizar `vault/00_Dashboard.md`
