# Sprint 3 · MVP-7 Gate CI/CD

## Aprendizajes

1. **`tiene_violacion: bool` en tool-use es crítico.** Sin él, el LLM siempre devuelve algún control (nunca responde "nada que reportar"). Con el campo explícito, el LLM puede responder limpiamente "sin violación" para comentarios, refactors o imports neutros, eliminando falsos positivos.

2. **Heredocs (`<<'EOF'`) dentro de YAML rompen `check-yaml`.** El parser YAML interpreta `<<` como operador de merge, incluso dentro de bloques literales `run: |`. Solución: reemplazar el inline Python por parseo shell con `grep`/`sed`/`awk`, que no necesita heredocs.

3. **`per-file-ignores` de ruff para el patrón `load_dotenv()`.** Cuando `load_dotenv()` aparece entre bloques de imports (patrón heredado de sesión anterior), todos los imports siguientes reciben E402. La solución no destructiva es añadir `per-file-ignores` en `pyproject.toml` en lugar de reorganizar el archivo completo.

4. **`DiffAnalyzerDep` como dependencia FastAPI permite mocks limpios.** Al inyectar el `DiffAnalyzer` via `dependency_overrides`, los tests del endpoint no necesitan parchear nada internamente — siguen exactamente el mismo patrón de `test_api.py`.

5. **`ruff-format` como hook de pre-commit normaliza automáticamente.** Tras el primer intento de commit fallido, ruff-format reformateó los archivos. El segundo commit pasó todos los hooks sin intervención manual adicional.
