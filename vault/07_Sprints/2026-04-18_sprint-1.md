# Sprint 1 · Traductor Simbiótico sobre ISO 27001:2022

## Objetivo

Implementar el **Traductor Simbiótico funcional** sobre el corpus ISO 27001:2022: dado un JSON con un `DatosRedTeam`, ROSETTA devuelve un `DatosCompliance` válido citando el control ISO correcto del Anexo A — sin alucinar controles inexistentes.

**Criterio de aceptación** (de `docs/ROADMAP.md#mvp-1`): los 5 hallazgos canónicos de `vault/MOC_Hallazgos.md` devuelven el control correcto top-1 o top-3 sin alucinar artículos inexistentes.

## Bloqueo declarado ✅ RESUELTO

Corpus descargado: `corpus/iso27001/iso27001-2022-intuitem.yaml`
- Fuente: intuitem/ciso-assistant-community (AGPL-3.0, uso interno)
- 93 controles ISO 27001:2022, traducciones al español
- Controles clave verificados: A.5.15, A.8.5, A.8.16, A.8.24, A.6.4 ✅

## Aprendizajes

- ChromaDB type stubs son más estrictos que la API real → `# type: ignore[arg-type]` necesario en 3 puntos
- `FuenteRedTeam` no incluye fuentes Blue Team (Wazuh) — el adaptador normaliza a `"otro"` antes de crear `DatosRedTeam`
- El test E2E real requiere LLM vivo; con mocks se valida el pipeline sin coste
