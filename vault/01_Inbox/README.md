# Inbox

Todo entra aquí primero. Notas sueltas, ideas a medio cocinar, capturas rápidas de ocurrencias. Procesar periódicamente y mover a la carpeta correcta con su plantilla.

## Flujo sugerido

1. Escribir la nota aquí con nombre `YYYY-MM-DD_titulo-corto.md`.
2. Una vez por semana, revisar y reubicar cada nota a `02_ADR`, `03_Normativa`, `05_Hallazgos`, etc. con su plantilla completa.
3. Si después de procesar queda sin destino claro, tag como `#idea` y mover a `05_Hallazgos/ideas/`.
